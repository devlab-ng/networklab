# Network Lab #

## Overview ##
The aim of this project is to setup a network lab infrastructure for a fictitious company named Acme. The lab is intended to cover all use cases and scenarios which are involved in terms of learning the networking fundamentals to help design and immplement the network infrastructure.

## Process ##
The network lab setup will cover multiple steps incorporating a weekly build which will be tracked via a tracker. The weekly updates will also be published as part of the README.md updates to ensure that the details of the progress are being tracked.

The main focus is to use infrastructure-as-code (IaC) leveraging all open source technologies to setup the network infrastructure.
